# Week 4: GeoDev Lab Africa Project Progress

## GeoDev Lab Africa, Cohort One

**Project:** Spatial Analysis of Primary Healthcare Accessibility in Anambra West LGA, Anambra State, Nigeria

## Overview

Week 4 forms part of the continuing GeoDev Lab Africa project workflow.

The repository currently contains the Week 4 working file, watsup.docx, which is retained as part of the project record.

## Project Progress So Far

- **Week 1:** Defined the healthcare accessibility problem, study area and research direction.
- **Week 2:** Collected and documented the spatial datasets required for analysis.
- **Week 3:** Performed CRS preparation, reprojection, clipping and data-quality checks.
- **Week 4:** Continued the project workflow and documentation.

## Current Project Direction

The broader project remains focused on understanding healthcare accessibility in Anambra West through the relationship between:

- Primary Healthcare Centres
- Settlements
- Population
- Roads
- Waterways
- Administrative boundaries
- Seasonal and flood-related geographic constraints
