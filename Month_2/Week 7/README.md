# Week 7

## Python ward area analysis

Week 7 applies Python to a simple ward-area classification exercise.

- `wards.csv` contains four wards and their area values in square kilometres.
- `analyse.py` reads `wards.csv`, converts each area from square kilometres to hectares and classifies each ward as **large** or **small**.
- A ward is classified as **large** when its area is greater than 9 km². Otherwise, it is classified as **small**.

## Week 7 deliverable

The analysis script successfully classifies all four wards in the supplied dataset.
